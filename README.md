# 週末ニュース番組

ニュースや保存した記事を持ち寄り、AI司会と一週間を振り返るための、情報源に依存しないスキルです。曜日ごとのニュース紹介、テーマを選んでの対話、最後の「あっぱれ」まで進めます。

## 使い方

`skills/weekly-news-program` を、使用するエージェントのスキルを置く場所にコピーします。スキルに対応しない環境では、[SKILL.md](skills/weekly-news-program/SKILL.md) を指示として渡してください。

対象週と素材を渡し、例えば次のように依頼します。

> 今週のニュースを曜日ごとに紹介し、保存した話題から論点を一緒に決めて、御意見番形式で振り返ってください。

入力は、ニュース一覧、RSSからの出力、ブックマークのエクスポート、リンク集など自由です。最低限、タイトルと元リンクがあると使いやすくなります。日付が分かる場合は、公開日・保存日・一覧掲載日のどれかも添えてください。ニュース紹介用と対話用に別の一覧を渡すこともできます。

```text
対象週: 2026-01-05〜2026-01-11
ニュース:
- 2026-01-05（掲載日）｜記事のタイトル｜https://example.com/news
対話したい話題:
- 日付不明｜気になった投稿｜https://example.com/post
```

番組名、言語、扱うジャンル、紹介件数、コメントの進め方は依頼時に変更できます。素材は例であり、ニュース取得や定期実行の仕組みは含みません。リンク先へのアクセスや取得方法は利用環境によって異なります。

スキルは公開・投稿・外部送信を自動では行いません。共有する前に、元記事の内容、出典、個人情報、公開する権利を確認してください。
